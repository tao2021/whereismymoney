Key Optimization Concepts:
  - Coalescing: Ensure threads access consecutive memory addresses
  - Tiling: Load data into shared memory for reuse
  - Bank Conflicts: Avoid multiple threads accessing same memory bank
  - Latency Hiding: Overlap computation with memory access
  - Tensor Cores: Use specialized hardware for matrix operations
